🌤️ Weather Bot

A simple and user-friendly Weather Bot Website that provides weather information for users based on their location or selected city.

🌐 Website

Live Website: http://localhost:5173/

«Note: This is a local development URL, so it will only work when the project is running on your computer.»

✨ Features

- 🌡️ Displays current weather information
- 📍 Search weather by city/location
- 🌤️ Shows weather conditions
- 💨 Displays additional weather details
- 📱 Responsive and user-friendly interface
- 🤖 Weather Bot interface for easy interaction
- ⚡ Fast and simple user experience

🛠️ Technologies Used

- HTML5 – Website structure
- CSS3 – Styling and responsive design
- JavaScript – Website functionality
- Weather API – Fetching real-time weather information

🚀 How to Run the Project

1. Clone the Repository

git clone <your-github-repository-link>

2. Open the Project

Navigate to the project folder:

cd Weather-Bot

3. Start the Website

If the project uses a development server such as Vite:

npm install
npm run dev

The website will normally be available at:

http://localhost:5173/

🔑 API Configuration

If the project uses a weather API, add your API key to the appropriate environment/configuration file.

Example:

WEATHER_API_KEY=your_api_key_here

Do not upload your API key publicly to GitHub.
